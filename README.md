# 💼 Personal Portfolio Website

A modern, responsive, and professional **Portfolio Website** built using **HTML5, CSS3, and Bootstrap 5**. This project showcases personal information, technical skills, services, projects, blog posts, and contact details in a clean and user-friendly interface.

## 🚀 Live Demo

🔗 **Live Website:**  
https://durjoy-mahanto.github.io/portfolio-website/

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Durjoy-mahanto/portfolio-website.git
```

Open the project folder:

```bash
cd portfolio-website
```

Run:

```
index.html
```

using your preferred browser.
